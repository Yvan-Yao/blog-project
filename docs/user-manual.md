## 一、访客指南

无需注册，即可完整浏览博客内容。

### 1.1 浏览文章

打开博客首页（`http://localhost:5173`），你会看到：

- **文章卡片列表**：每张卡片展示文章标题、摘要、发布时间、分类标签
- **浏览量和评论数**：右下角显示
- 点击任意文章卡片进入阅读页

### 1.2 搜索文章

在首页顶部搜索框中：
1. 输入关键词（标题或摘要中包含的词）
2. 点击 **搜索** 按钮或按回车
3. 结果实时更新，显示匹配到的文章数量

### 1.3 按分类筛选

- 分类标签排列在搜索框下方
- 点击某个分类标签，只显示该分类下的文章
- 点击 **全部** 回到所有文章

### 1.4 阅读文章

文章详情页包含：
- 标题和分类
- 作者、发布时间、浏览量
- 正文内容（支持代码高亮、引用块等 Markdown 格式）
- 评论区（**查看**评论无需登录）

> **注意**：访客可以查看评论，但发表评论需要先注册并登录。

## 二、注册与登录

### 2.1 注册账号

1. 点击右上角 **注册** 按钮
2. 填写以下信息：
   - **用户名**：2-20 字符，唯一，不可与他人重复
   - **邮箱**：有效邮箱格式
   - **密码**：至少 6 位
   - **确认密码**：与上方密码一致
3. 点击 **创建账号**

注册成功后自动登录，跳转到首页。

> **管理员注册**：如果你知道管理员注册码（`adminSecret`），在注册表单中填入即可注册为管理员账号（不对外展示此字段，需技术配置）。

### 2.2 登录

1. 点击右上角 **登录** 按钮
2. 输入用户名和密码
3. 点击 **登录**

登录状态会保持 7 天（即使关闭浏览器）。

### 2.3 退出登录

点击右上角用户头像 → 下拉菜单 → **退出登录**

## 三、普通用户指南

登录后，你获得以下能力：

### 3.1 收藏文章

在浏览文章时，你可以收藏喜欢的文章以便日后查阅：

- **首页文章卡片**：每张卡片右下角有一个 🔖 书签图标，点击即可收藏（实心图标表示已收藏），再次点击取消收藏
- **文章详情页**：正文上方有醒目的「收藏文章」按钮，点击收藏/取消收藏
- **查看收藏**：点击右上角头像 → **我的收藏** 查看所有收藏的文章

### 3.2 查找我的文章

登录后可以快速找到自己写的所有文章：

- 点击右上角头像 → **我的文章**
- 页面显示你写的所有文章（草稿 + 已发布）
- 支持按状态筛选：全部 / 已发布 / 草稿
- 点击文章可直接跳转阅读

### 3.3 发表评论

1. 打开任意已发布的文章
2. 滚动到底部评论区
3. 在输入框中写下你的想法（最多 1000 字）
4. 点击 **发送**

评论立即显示在评论区，无需审核。

### 3.4 回复评论

1. 找到你想回复的评论
2. 点击评论右下角的 **回复** 按钮
3. 输入框自动显示 `回复 @用户名`
4. 写下你的回复，点击 **发送**

回复会缩进显示在被回复评论的下方。

### 3.5 删除自己的评论

在你自己发表的评论旁，有一个小型 **删除** 图标：
1. 点击垃圾桶图标
2. 确认删除（删除后不可恢复）

### 3.6 写文章（发帖）

1. 点击导航栏的 **写文章** 按钮
2. 填写文章内容：

   | 字段 | 说明 | 必填 |
   |------|------|------|
   | 标题 | 文章标题（2-200字符） | ✅ |
   | 正文 | 支持 Markdown 语法 | ✅ |
   | 摘要 | 简短描述（最多200字）| ❌ |
   | 分类 | 选择归属分类 | ❌ |

3. **保存草稿**：点击 **草稿** 按钮，文章保存为草稿状态，游客不可见
4. **预览**：点击 **预览** 按钮查看渲染后的效果

> **注意**：普通用户创建的文章默认为草稿，需要管理员审核并发布后才公开可见。

### 3.7 Markdown 写作语法速查

```markdown
# 一级标题
## 二级标题
### 三级标题

**粗体文字**
*斜体文字*
~~删除线~~

- 无序列表项1
- 无序列表项2

1. 有序列表项1
2. 有序列表项2

[链接文字](https://url.com)

`行内代码`

```代码语言
多行代码块
```

> 引用文字

---  分隔线
```

## 四、管理员指南

管理员拥有最高权限，可以管理所有内容和用户。

> **如何成为管理员**：在注册时填写正确的 `adminSecret`，或由其他管理员在数据库中修改角色。

### 4.1 进入管理后台

登录管理员账号后：
- 点击右上角用户头像 → **管理后台**
- 或直接访问：`http://localhost:5173/admin`

### 4.2 仪表盘（数据概览）

管理后台首页展示：

| 指标 | 说明 |
|------|------|
| 注册用户 | 总用户数量 |
| 已发布文章 | 公开可见的文章数 |
| 草稿 | 未发布的文章数 |
| 评论总数 | 全站评论数 |
| 总浏览量 | 所有文章累计浏览次数 |
| 近7天发帖趋势 | 柱状图展示最近7天的发帖量 |

### 4.3 文章管理

进入 **文章管理** 页面，可以看到所有文章（包括草稿）：

**发布草稿文章**：
1. 在文章列表中找到状态为"草稿"的文章
2. 点击行右侧的 ✅ 发布图标
3. 文章立即公开可见

**编辑文章**：
1. 点击 ✏️ 铅笔图标
2. 修改内容并保存

**删除文章**：
1. 点击 🗑️ 垃圾桶图标
2. 确认删除（此操作不可撤销，相关评论也会被同时删除）

**管理员也可以直接发布**：在写文章页面，管理员会看到额外的 **发布** 按钮，可直接将文章设为已发布状态。

### 4.4 用户管理

进入 **用户管理** 页面，查看所有注册用户：

**删除用户**：
1. 找到目标用户行
2. 点击删除图标
3. 确认删除

> **注意**：不能删除当前登录的账号（自己）。删除用户会同时删除其发表的所有文章和评论。

### 4.5 评论管理

管理员可以在任意文章的评论区直接删除评论：

1. 打开文章详情页
2. 在评论区，管理员可以看到每条评论的 **删除** 按钮
3. 点击即可删除任意评论

### 4.6 发布文章的完整流程

```
用户写文章 → 保存为草稿
         ↓
管理员查看文章管理列表
         ↓
找到待审核的草稿
         ↓
点击"发布"图标 ✅
         ↓
文章公开可见，游客可搜索和访问
```

## 五、常见问题

**Q: 登录后刷新页面，提示需要重新登录？**

登录状态存储在浏览器的 `localStorage` 中，正常情况下不会丢失。如果频繁提示，可能是 Token 已过期（7天有效期），重新登录即可。

**Q: 我发表的文章为什么别人看不到？**

普通用户发表的文章默认为"草稿"状态，需要管理员在后台将其发布后才公开。你可以在"写文章"页面看到文章的状态。

**Q: 评论有字数限制吗？**

每条评论最多 1000 个字符。

**Q: 文章内可以插入图片吗？**

目前支持通过 Markdown 语法插入外部图片链接：

```markdown
![图片描述](https://图片URL)
```

**Q: 可以修改已发表的评论吗？**

目前系统不支持编辑评论，如需修改请先删除后重新发表。

**Q: 忘记密码怎么办？**

目前系统没有自助找回密码功能，请联系管理员重置。

**Q: 搜索不到想要的文章？**

搜索仅对文章**标题**和**摘要**进行检索，正文内容不在搜索范围内。建议使用文章中关键词的主题词搜索。
